# C1901 产品介绍

![C1901 Banner](/img/c1901-banner.png)

## 产品简介

**C1901**（Jetson Orin Nano Lite）是一款面向 **Jetson Orin Nano / Orin NX** 核心卡的高性价比载板。该载板基于官方参考设计精简并优化部分外围功能，在保留核心接口体验的同时显著降低整机成本。

## 产品特点

- 基于原厂参考方案开发，提供接近公版开发者套件的使用体验
- 支持 Jetson Orin Nano 4GB/8GB 与 Jetson Orin NX 8GB/16GB 核心卡（支持 Orin Nano 系列 **SUPER 模式**）
- 高品质 **6 层沉金 PCB**，采用全 MLCC 电容与镀金连接器
- 支持双路 **NVMe SSD** 存储扩展与 **M.2 Key E** 无线网卡

## 产品规格

| 规格 | 参数 |
|------|------|
| 供电电压 | 12V（兼容 9V–19V） |
| 电源接口 | DC5521（兼容 DC5525 插头） |
| 支持的核心卡 | Jetson Orin Nano 4GB/8GB、Jetson Orin NX 8GB/16GB |
| 以太网 | 1 × 千兆 RJ45 |
| 无线网卡 | 1 × M.2 Key E（2230） |
| 存储扩展 | 2 × M.2 Key M（NVMe SSD） |
| 显示 | 1 × HDMI（1080P） |
| USB | 3 × USB 3.2 Type-A + 1 × USB 2.0 Type-A |
| USB-C | 1 × USB Type-C（USB 2.0，仅用于烧录固件） |
| 相机接口 | 2 × CSI，22-pin |
| 其余接口 | 与原厂载板一致（40-pin 扩展排针、12-pin 按钮/调试接口、风扇接口） |
| RTC 电池 | 支持，MX1.25-2P，3V（V1.2 及以上版本） |
| PoE 供电 | 不支持 |
| 工作温度 | 0℃–45℃ |

::: warning 注意事项
- 推荐使用 12V 电源供电（兼容 9V–19V），请确保电源具备充足的输出功率。
- 电源接口为 DC5521，兼容 DC5525 插头。
- 输入电压高于 15V 且负载较大时，请加强散热。
- 载板具备电源输入反接保护，但请勿反接电源。
- 每组 USB 接口合计最大输出电流为 2.5A。
- 背面 M.2 Key E 无线网卡插槽与 M.2 2230 插槽相较原厂载板为对称反向布局。
- **载板断电后才能插拔核心卡，严禁带电插拔。**
- NVMe SSD 必须使用**单面版本**；双面 SSD 可能发生干涉并引起短路。
:::

## 版本迭代记录

| 版本 | 日期 | 备注 |
|------|------|------|
| V1.0 | 2023 Q3 | C1901 首个正式发布版本 |
| V1.1 | 2024 Q1 | 调整载板硬件功耗限制，修复搭配 Orin NX 16GB 核心卡在极限负载下偶发断电重启的问题 |
| V1.2 | 2024 Q2 | 新增 RTC 后备电池接口 |
| V1.3 | 2025 Q1 | 1. 修改 CSI 摄像头接口线序，与原厂载板保持一致<br/>2. 修复 40-pin 排针部分 GPIO 引脚（12 / 35 / 38 / 40 号引脚）异常问题<br/>3. 修复风扇调速相关问题<br/>4. 移除所有 I²C 接口的板载上拉电阻<br/>5. 不再针对 Jetson Nano / Xavier NX / TX2 NX 等停产核心卡做完整外设适配（仅保留部分基础功能，详见下方兼容性表）<br/>6. 移除载板硬件功耗限制 |

::: warning 固件与设备树说明
- **V1.3 版本**刷机后需配置专用设备树文件以启用全部 USB 通道，详见 [C1901 刷机教程](/flashing-guide/c1901-flashing) 与 [USB 设备树配置说明](/orin-nano-series/usb-config)。
- **V1.2 版本**推荐使用 **JetPack 5.1.4** 固件；V1.2 及更早版本无需替换 V1.3 专用设备树。
:::

## 部分功能及接口介绍

### HDMI 显示接口 (2) 与运行说明

- 板载 HDMI 接口由核心卡 DP 信号转换输出，在官方原厂固件下最高支持 **1080P** 分辨率。
- 载板在某些特定功率负载下可能产生轻微电感啸叫声，属正常物理现象，不影响系统稳定工作。

### 40-pin 扩展排针 (7)

40-pin GPIO 扩展排针中的 5V 输出具备倒灌保护，最大输出电流为 0.7A。引脚定义如下图所示：

![C1901 40-pin 排针引脚定义](/img/c1901-40pin.webp)

*40-pin 扩展排针引脚定义*

### 12-pin 按钮 / 调试接口 (9)

12-pin 排针包含电源指示灯、调试串口（UART）、强制恢复（`FC REC`）与电源按键（`PWR BTN`）等信号，线序如下图所示：

![C1901 12-pin 按钮/调试接口引脚定义](/img/c1901-12pin.png)

*12-pin 按钮 / 调试接口引脚定义*

### RTC 电池接口 (4)

接口型号为 MX1.25-2P，使用 3V 后备电池。连接时请确认正负极，**禁止反接**。

![C1901 RTC 电池接口](/img/c1901-rtc.png)

*RTC 电池接口*

接入电池后还需配置系统才能启用 RTC 时钟，详情参见 [RTC 说明](/orin-nano-series/peripherals#_5-rtc-接口)。
