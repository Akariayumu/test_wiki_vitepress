## 产品简介

**C1902** 是一款面向 **Jetson Orin Nano / Orin NX** 核心卡研发的全功能兼容载板。该载板基于官方参考设计开发，完整兼容官方开发者套件的所有接口功能（包括全速 10Gbps USB 3.2 Type-A 与 USB Type-C 接口），可直接烧录官方 Developer Kit 固件。

## 产品特点

- 基于原厂参考方案开发，所有接口功能与原厂一致，可**直接烧录 Developer Kit 固件**
- 支持 Jetson Orin Nano 4GB/8GB 与 Jetson Orin NX 8GB/16GB 全系列 **SUPER 模式**（V1.1 及以上版本）
- 高品质 **6 层沉金 PCB**，采用全 MLCC 电容与镀金连接器
- 支持双路 **NVMe SSD** 存储扩展与 **M.2 Key E** 无线网卡

## 产品规格

| 规格 | 参数 |
|------|------|
| 供电电压 | 12V（兼容 9V–19V） |
| 电源接口 | DC5525（V1.0/V1.1 为 DC5521） |
| 支持的核心卡 | Jetson Orin Nano 4GB/8GB、Jetson Orin NX 8GB/16GB |
| 以太网 | 1 × 千兆 RJ45 |
| 无线网卡 | 1 × M.2 Key E（2230） |
| 存储扩展 | 2 × M.2 Key M（NVMe SSD） |
| 显示 | 1 × DisplayPort 1.2 |
| USB | 4 × USB 3.2 Type-A（10Gbps） |
| USB-C | 1 × USB 3.2 Type-C（10Gbps） |
| 相机接口 | 2 × CSI，22-pin |
| 其余接口 | 与原厂载板一致（40-pin 扩展排针、12-pin 按钮/调试接口、风扇接口、启动按钮） |
| RTC 电池 | 支持，MX1.25-2P，3V |
| PoE 供电 | 不支持 |
| 工作温度 | 0℃–45℃ |

::: warning 注意事项
- 推荐使用 12V 电源供电（兼容 9V–19V），请确保电源功率充足。
- 输入电压高于 15V 且负载较大时，请加强散热。
- 载板具备电源输入反接保护，但请勿反接电源。
- 每组 USB 接口最大输出电流为 2.5A，过流时自动切断 USB 供电。
- 背面 M.2 Key E 与 M.2 2230 接口相较原厂载板为对称反向布局。
- NVMe SSD 必须使用**单面版本**；双面 SSD 可能发生干涉或短路。
:::

::: danger 安全警告
**载板断电后才能插拔核心卡**，严禁带电插拔，以免损坏核心卡或载板。
:::

## 部分功能及接口介绍

### 启动按钮 (10)

- **系统运行时：** 短按呼出系统关机界面，长按 10 秒强制关机。
- **系统关机时：** 短按开机。

### 40-pin 扩展排针 (14)

40-pin GPIO 扩展排针的 5V 输出具备倒灌保护，最大输出电流为 0.8A，过流时自动关断。引脚定义请以实际使用的核心卡为准。

![C1902 40-pin 排针引脚定义](/img/c1902-40pin.webp)

*40-pin 扩展排针引脚定义*

### 12-pin 按钮 / 调试接口 (11) 与 CAN 接口 (12)

12-pin 排针包含电源 LED、调试串口（UART）、Latch Set、系统复位、强制恢复（`FC REC`）与电源按钮（`PWR BTN`）等信号，线序如下图所示。板载 4-pin CAN 焊盘（标号 12）引出核心卡原生 `CAN RX / CAN TX` 逻辑信号，外接 CAN 收发器及测试方法参见 [CAN 总线说明](/orin-nano-series/peripherals#_4-can-总线)。

![C1902 12-pin 调试接口引脚定义](/img/c1902-12pin.png)

*12-pin 按钮 / 调试接口引脚定义*

### RTC 电池接口 (16)

接口型号为 MX1.25-2P，使用 3V 后备电池。连接时请确认正负极，**禁止反接**。

![C1902 RTC 电池接口](/img/c1902-rtc.png)

*RTC 电池接口*

接入电池后还需配置系统才能启用 RTC 时钟，详情参见 [RTC 说明](/orin-nano-series/peripherals#_5-rtc-接口)。
