# C1902 V2 产品介绍

![C1902 V2 Banner](/img/c1902v2-banner.webp)

## 产品简介

**C1902 V2** 是一款针对 Jetson Orin Nano 及 NX 核心卡进行研发的**工业级**载板。该底板基于公版方案进行重构，并对芯片进行工业级优化，在兼容官方设计套件功能的同时拥有更好的稳定性和可靠性。

## 产品特点

- C1902 V2 基于原厂方案进行开发，所有接口功能与原厂一致，可直接烧录 Developer Kit 固件
- 完美支持 Orin Nano 4GB/8GB 与 Orin NX 8GB/16GB 的 SUPER 模式
- 重新设计的供电方案，带来更低的发热和更高的效率
- 高品质 8 层 PCB，所有线路均做严格阻抗匹配
- 基础工业级的温度范围，带来更好的稳定性和可靠性

## 产品规格

| 规格 | 参数 |
|------|------|
| 供电电压 | 12V（兼容 9V–19V） |
| 电源接口 | DC5525 |
| 支持的核心 | Jetson Orin Nano 4GB/8GB、Jetson Orin NX 8GB/16GB |
| 以太网 | 1 × 千兆 RJ45 |
| 无线网卡 | 1 × M.2 Key E |
| 存储扩展 | 2 × M.2 Key M（NVMe SSD） |
| 显示 | 1 × DisplayPort 1.2 |
| USB | 4 × USB 3.2 Type-A（5Gbps） |
| USB-C | 1 × USB 3.2 Type-C（10Gbps） |
| 相机接口 | 2 × CSI，22-pin |
| 其余接口 | 与原厂载板一致；另有 12-pin 按钮/调试接口、风扇接口和 REC 按钮 |
| RTC 电池 | 支持，MX1.25-2P，3V |
| PoE 供电 | 不支持 |
| 工作温度 | -20℃–55℃ |

> - 推荐使用 12V 电源，支持 9V–19V 输入；请确保电源功率充足。
> - 输入电压高于 15V 且负载较大时，请加强散热。
> - 载板具备电源输入反接保护，但请勿反接电源。
> - 每组 USB 接口最大输出电流为 2.5A；过流时会切断 USB 供电。
> - 背面 M.2 Key E 与 M.2 2230 接口的布局相较原厂载板为对称反向布局。
> - **载板断电后才能插拔核心卡。**
> - SSD 必须使用单面版本；双面 SSD 可能发生干涉或短路。

## 部分功能及接口介绍

### 电源输入 (1)

使用 DC5525 电源接口，推荐输入 12V，支持 9V–19V。高于 15V 且负载较大时请加强散热。

### REC 按钮 (13)

- **系统关机时：** 同时按住按钮并上电进入恢复模式。

![C1902 V2 REC 按钮](/img/c1902v2-rec-button.webp)

### 40-pin 扩展排针 (9)

40-pin GPIO 排针的 5V 输出带倒灌保护，最大输出电流为 0.8A，过流时会关断。引脚定义请以实际使用的核心卡为准。

![C1902 40-pin 排针引脚定义](/img/c1902-40pin.webp)

### 12-pin 按钮/调试接口 (12)

接口包含电源 LED、UART、Latch Set、系统复位、强制恢复和电源按钮等信号。线序如下图所示：

![C1902 12-pin 按钮/调试接口定义](/img/c1902-12pin.png)

### RTC 电池接口 (16)

接口型号为 MX1.25-2P，使用 3V 电池。连接时请确认正负极，禁止反接。

![C1902 RTC 电池接口](/img/c1902-rtc.png)

接入电池后还需配置才能启用 RTC 时钟，详情参见 [RTC 说明](/orin-nano-series/peripherals#_5-rtc接口)。
