# C1902 V2 产品介绍

![C1902 V2 Banner](/img/c1902v2-banner.webp)

## 产品简介

**C1902 V2** 是一款面向 **Jetson Orin Nano / Orin NX** 核心卡研发的**工业级**载板。该载板基于官方参考设计重构，选用工业级关键元器件并优化供电架构，在完整兼容官方开发者套件功能的同时具备更高的稳定性与可靠性。

## 产品特点

- 基于原厂参考方案开发，所有接口功能与原厂一致，可**直接烧录 Developer Kit 固件**
- 完美支持 Orin Nano 4GB/8GB 与 Orin NX 8GB/16GB 的 **SUPER 模式**
- **重新设计的供电方案**，带来更低的发热和更高的转换效率
- 高品质 **8 层 PCB**，所有高速信号线路均做严格阻抗匹配
- 具备 **-20℃–55℃ 工业级**工作温度范围，带来更高的稳定性和可靠性

## 产品规格

| 规格 | 参数 |
|------|------|
| 供电电压 | 12V（兼容 9V–19V） |
| 电源接口 | DC5525 |
| 支持的核心卡 | Jetson Orin Nano 4GB/8GB、Jetson Orin NX 8GB/16GB |
| 以太网 | 1 × 千兆 RJ45 |
| 无线网卡 | 1 × M.2 Key E（2230） |
| 存储扩展 | 2 × M.2 Key M（NVMe SSD） |
| 显示 | 1 × DisplayPort 1.2 |
| USB | 4 × USB 3.2 Type-A（5Gbps） |
| USB-C | 1 × USB 3.2 Type-C（10Gbps） |
| 相机接口 | 2 × CSI，22-pin |
| 其余接口 | 与原厂载板一致；另有 12-pin 按钮/调试接口、风扇接口和 REC 按钮 |
| RTC 电池 | 支持，MX1.25-2P，3V |
| PoE 供电 | 不支持 |
| 工作温度 | **-20℃–55℃** |

::: warning 注意事项
- 推荐使用 12V 电源，支持 9V–19V 输入；请确保电源功率充足。
- 输入电压高于 15V 且负载较大时，请加强散热。
- 载板具备电源输入反接保护，但请勿反接电源。
- 每组 USB 接口最大输出电流为 2.5A；过流时会切断 USB 供电。
- 背面 M.2 Key E 与 M.2 2230 接口的布局相较原厂载板为对称反向布局。
- **载板断电后才能插拔核心卡，严禁带电插拔。**
- NVMe SSD 必须使用**单面版本**；双面 SSD 可能发生干涉或短路。
:::

## 版本迭代记录

| 版本 | 日期 | 备注 |
|------|------|------|
| V2.0 | 2026 Q3 | 1. 修改了载板的 USB 3.2 Hub 芯片，由消费级芯片更换为工业级芯片（Type-A 带宽由 10Gbps 调整至 5Gbps）<br/>2. 修改了载板时序单片机，由 STM32 更换为 GD32<br/>3. 优化了核心卡供电方案，性能不变的情况下带来更低的核心卡功耗和发热<br/>4. 供电方案优化，增加了固态电容及聚合物电容作为输入输出电容<br/>5. DP、USB Type-A 座子由卷口更换为平口<br/>6. 原板载 PWR 按钮修改为 REC 按钮 |

V1.x 版本资料请参见 [C1902 产品介绍](/c1902/c1902)。

## 部分功能及接口介绍

### 电源输入 (1)

使用 DC5525 电源接口，推荐输入 12V，支持 9V–19V。输入电压高于 15V 且负载较大时请加强散热。

### REC 按钮 (13)

- **系统关机时：** 按住 `REC` 按钮并接通电源即可进入恢复模式（Force Recovery）。

::: tip 外接电源按键说明
C1902 V2 将原板载电源键改为独立的 `REC` 按钮（默认上电自动开机）。如需外接开关机按键，可通过 **12-pin 按钮 / 调试接口 (12)** 的 Pin 12（`PWR BTN`）与 Pin 11（`GND`）引出。
:::

![C1902 V2 REC 按钮](/img/c1902v2-rec-button.webp)

*REC 按钮位置*

### 40-pin 扩展排针 (9)

40-pin GPIO 扩展排针的 5V 输出带倒灌保护，最大输出电流为 0.8A，过流时会关断。引脚定义请以实际使用的核心卡为准。

![C1902 40-pin 排针引脚定义](/img/c1902-40pin.webp)

*40-pin 扩展排针引脚定义*

### 12-pin 按钮 / 调试接口 (12) 与 CAN 接口 (11)

12-pin 接口包含电源 LED、调试串口（UART）、Latch Set、系统复位、强制恢复和电源按钮等信号，线序如下图所示。板载 4-pin CAN 焊盘（标号 11）引出核心卡原生 `CAN RX / CAN TX` 逻辑信号，外接 CAN 收发器及通信测试方法请参见 [CAN 总线说明](/orin-nano-series/peripherals#_4-can-总线)。

![C1902 12-pin 按钮/调试接口定义](/img/c1902-12pin.png)

*12-pin 按钮 / 调试接口引脚定义*

### RTC 电池接口 (16)

接口型号为 MX1.25-2P，使用 3V 后备电池。连接时请确认正负极，**禁止反接**。

![C1902 RTC 电池接口](/img/c1902-rtc.png)

*RTC 电池接口*

接入电池后还需配置系统才能启用 RTC 时钟，详情参见 [RTC 说明](/orin-nano-series/peripherals#_5-rtc-接口)。
