# C2401 产品介绍

![C2401 Banner](/img/c2401-banner.png)

## 产品简介

**C2401** 是一款面向 **Jetson Orin Nano / Orin NX** 核心卡研发的高密度小尺寸载板。在紧凑的外形体积下提供完备的工业与机器视觉接口，包含**双以太网口**、**双路 USB 3.2 接口**以及丰富的扩展能力（支持扩展 **4G/5G 通信模组**等外设）。

## 产品特点

- 配备车规级 **E-fuse** 电子保险丝芯片，集成过压、欠压、短路、过流及反接保护
- 选用超低内阻 Buck 芯片与合金扁线电感，具备低发热与高饱和电流特性
- 高品质 **8 层 2U 沉金塞孔工艺 PCB**，PCB 板框尺寸仅 **55 × 92 mm**（含外凸接口总尺寸 56 × 94 mm）
- 提供双路 USB 3.2（10Gbps）与双网口（1 × 千兆 + 1 × 2.5G，2.5G 网口支持 PTP 与 16KB 巨型帧）
- M.2 Key M 与 Key E 同面（背面）设计，更换无线网卡或固态硬盘无需拆卸核心卡

## 产品规格

| 规格 | 参数 |
|------|------|
| 供电电压 | 12V（支持 10V–30V，欠压保护阈值 9.5V，过压保护阈值 31V） |
| 电源接口 | XT30 |
| 支持的核心卡 | Jetson Orin Nano 4GB/8GB、Jetson Orin NX 8GB/16GB |
| 以太网 | 1 × 2.5G RJ45（16KB 巨型帧、PTP）+ 1 × 千兆 RJ45（9KB 巨型帧） |
| 无线网卡 | 1 × M.2 Key E（2230） |
| 存储扩展 | 1 × M.2 Key M（2230，NVMe SSD） |
| 显示 | 1 × Mini HDMI 2.1 |
| USB | 2 × USB 3.2 Type-A（10Gbps）+ 1 × USB 2.0（GH1.25-4P） |
| USB-C | 1 × USB Type-C（USB 2.0，仅用于烧录固件） |
| 相机接口 | 1 × CSI，22-pin |
| 其余接口 | UART、CAN、I²C、SPI、GPIO、USB 3.0（通过 30-pin 扩展排母引出） |
| RTC 电池 | 支持，2-pin 后备时钟电池接口，3V |
| PoE 供电 | 不支持 |
| 工作温度 | 0℃–45℃ |

::: warning 注意事项
- 推荐使用 12V 电源供电（支持 10V–30V 输入，欠压保护阈值 9.5V，过压保护阈值 31V）；输入电压高于 15V 且高负载运行时请注意加强散热。
- 载板具备电源输入反接保护，但请勿反接电源。
- 每组 USB 接口最大输出电流为 2.5A。
- **载板断电后才能插拔核心卡，严禁带电插拔。**
- M.2 2230 NVMe SSD 建议使用**单面版本**，避免双面颗粒干涉。
:::

## 部分功能及接口介绍

### XT30 电源接口 (1)

![C2401 XT30 电源接口](/img/c2401-xt30.png)

*XT30 电源接口极性*

推荐输入电压为 **12V**（支持 **10V–30V**，欠压保护阈值 **9.5V**，过压保护阈值 **31V**）。

| 核心卡型号 | 推荐电源功率 | USBC-PD 供电规格（经诱骗线接入 XT30） |
|------------|--------------|---------------------------------------|
| Jetson Orin Nano 4GB / 8GB | ≥ 45W | 20V 2.25A |
| Jetson Orin NX 8GB / 16GB | ≥ 60W | 20V 3A |

::: warning 供电方式说明
**板载 USB Type-C 接口（标号 3）仅用于烧录固件，不支持供电输入**，请勿将 PD 充电器直接插入板载 Type-C 口为其供电。上表 `USBC-PD` 列仅在使用 **USB-C PD 转 XT30 诱骗线**接入 **XT30 电源接口（标号 1）** 供电时适用。
:::

### Power / REC 按钮与功能拨码开关 (4, 5, 16)

- **进入恢复模式：** 断电状态下按住 `REC` 按钮再接通电源（恢复模式维持约 60 秒，若未检测到宿主机连接将自动正常启动）。

![C2401 REC 按钮](/img/c2401-rec-button.png)

*REC 按钮位置*

- 也可将背面**拨码开关 3** 拨至 `ON`，每次上电自动进入恢复模式：

![C2401 拨码开关 3](/img/c2401-switch-rec.png)

*拨码开关 3（REC）*

- **Power 启动按钮：** 系统运行时短按一次呼出关机界面、长按 10 秒强制关机；关机状态下短按一次开机。

![C2401 启动按钮](/img/c2401-pwr-button.png)

*Power 按钮位置*

- 将背面**拨码开关 2** 拨至 `ON` 可禁用上电自动开机；**拨码开关 1** 拨至 `ON` 可接入 CAN 总线 120Ω 终端电阻：

![C2401 拨码开关 2](/img/c2401-switch-power.png)

*拨码开关 2（禁用上电自启）*

| 拨码位 | 板面丝印 | `ON` 状态功能 | 默认状态 |
|--------|----------|---------------|----------|
| 1 | `CAN 120R` | 接入 CAN 总线 120Ω 终端电阻 | `OFF`（不接入） |
| 2 | `AUTO ON DIS` | 禁用上电自动开机（需按 Power 键开机） | `OFF`（上电自启） |
| 3 | `REC` | 每次上电自动进入恢复模式（Force Recovery） | `OFF`（正常启动） |
| 4 | — | 预留 | `OFF` |

::: warning 拨码开关复位提醒
若通过将拨码开关 3 拨至 `ON` 进入恢复模式刷机，**在宿主机识别设备后或刷机完成前请务必将其拨回 `OFF`**，否则刷机重启阶段会再次锁死在恢复模式导致超时失败。
:::

### 30-pin 扩展排母 (18)

背面配备 `2 × 15-pin`（1.27 mm 间距）扩展排母，Pin 1 位置与完整引脚定义如下图所示：

![C2401 30-pin 扩展排母位置](/img/c2401-ext-connector.png)

*30-pin 扩展排母 Pin 1 位置*

![C2401 30-pin 引脚定义](/img/c2401-pinout-30.png)

*30-pin 扩展排母引脚定义*

::: warning 引脚电气与配置说明
- `VCC_IN` 电压与外部输入电源电压一致（直通），最大持续电流 3A；`VDD_5V` 与 `VDD_3V3` 最大输出电流各为 1A。
- **I²C、GPIO、SPI、UART 所有信号引脚均为 3.3V 逻辑电平**，请勿直接接入 5V 电平信号。
- `PG`（Power Good）信号：核心卡正常工作时输出高电平。
- 第 13 / 15 / 19 / 21 脚引出的 USB 3.0 通道在官方固件中默认关闭，启用方法参见 [USB 配置说明](/orin-nano-series/usb-config)。
:::

### RJ45 网口 (8, 9)

- **2.5G 以太网接口 (8)**（靠近 USB 口侧，背面丝印 `ETH2 2.5G`）：采用 **RTL8125** 芯片，支持 PTP 与 16KB 巨型帧，**刷入系统后需安装驱动**方可使用，详见 [网卡驱动安装教程](/orin-nano-series/network-driver)。
- **千兆以太网接口 (9)**（靠近板角侧，背面丝印 `ETH1 1G`）：采用 **RTL8111** 芯片，支持 9KB 巨型帧，系统免驱即插即用。

### M.2 布局 (19, 20)

M.2 Key M（2230 NVMe SSD，标号 19）与 M.2 Key E（2230 无线网卡，标号 20）均位于载板背面同侧，在整机或载板上更换无线网卡与固态硬盘时无需拆卸正面核心卡与散热器（位置详见上方[背面接口布局](#接口布局)）。
