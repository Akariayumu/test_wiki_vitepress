# C1901 Introduction

![C1901 Banner](/img/c1901-banner.png)

## Overview

The **C1901** (Jetson Orin Nano Lite) is a cost-effective carrier board designed for **Jetson Orin Nano / Orin NX** modules. Based on the official reference design, it streamlines and optimizes selected peripheral circuits to significantly reduce overall system cost while preserving core interface functionality.

## Features

- Developed from the official reference design for an experience close to the reference developer kit
- Supports Jetson Orin Nano 4GB/8GB and Jetson Orin NX 8GB/16GB modules (supports **SUPER mode** on Orin Nano series)
- High-quality **6-layer ENIG PCB** with all-MLCC capacitors and gold-plated connectors
- Supports dual **NVMe SSD** storage slots and an **M.2 Key E** wireless card

| USB | 3 × USB 3.2 Type-A + 1 × USB 2.0 Type-A |
| USB-C | 1 × USB Type-C (USB 2.0, for flashing firmware only) |
| Camera | 2 × CSI, 22-pin |
| Other interfaces | Same as the reference board (40-pin expansion header, 12-pin button/debug header, fan header) |
| RTC battery | Supported, MX1.25-2P, 3V (V1.2 and later) |
| PoE | Not supported |
| Operating temperature | 0 °C to 45 °C |

::: warning Notes
- A 12V power supply is recommended (9V–19V input supported); ensure the power supply provides sufficient wattage.
- The power jack is DC5521 and is compatible with DC5525 plugs.
- Improve cooling when the input voltage exceeds 15V under heavy load.
- The carrier board includes reverse-polarity protection on the power input, but never connect power in reverse.
- Each USB port group supplies up to 2.5A total.
- Compared with the reference carrier board, the rear M.2 Key E wireless slot and M.2 2230 slot are mirrored.
- **Only insert or remove the Jetson module when the carrier board is powered off.**
- Use **single-sided NVMe SSDs** only; double-sided SSDs may cause mechanical interference and short-circuiting.
:::

## Selected Functions and Interfaces

### HDMI Display Port (2) and Operating Notes

- The onboard HDMI port is converted from the module's DisplayPort output and supports up to **1080P** resolution under stock reference firmware.
- Under certain load profiles, the inductors may produce a faint acoustic whine; this is normal physical behavior and does not affect system stability.

### 40-pin Expansion Header (7)

The 5V output on the 40-pin GPIO expansion header includes back-feed protection with a maximum current of 0.7A. The pinout is shown below:

![C1901 40-pin header pinout](/img/c1901-40pin.webp)

*40-pin expansion header pinout*

### 12-pin Button / Debug Header (9)

The 12-pin header exposes power LED, debug UART, Force Recovery (`FC REC`), and power button (`PWR BTN`) signals, as shown below:

![C1901 12-pin button/debug header pinout](/img/c1901-12pin.png)

*12-pin button / debug header pinout*

### RTC Battery Connector (4)

The connector uses an MX1.25-2P housing for a 3V backup battery. Verify polarity before connecting; **never reverse the polarity**.

![C1901 RTC battery connector](/img/c1901-rtc.png)

*RTC battery connector*

Software configuration is required after installing the battery to enable the RTC clock. See [RTC Interface](/en/orin-nano-series/peripherals#_5-rtc-interface).
