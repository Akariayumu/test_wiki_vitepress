# C1902 Introduction

::: tip New Version Available
The industrial-grade **C1902 V2** (8-layer PCB, `-20 °C to 55 °C`, dedicated REC button) is now available. See [C1902 V2 Introduction](/en/c1902v2/c1902v2). This page covers C1902 (V1.x) carrier boards.
:::

![C1902 Banner](/img/c1902-banner.png)

## Overview

The **C1902** is a full-featured reference-compatible carrier board developed for **Jetson Orin Nano / Orin NX** modules. Built upon the official reference design, it matches every interface of the official developer kit — including full-speed 10Gbps USB 3.2 Type-A and USB Type-C ports — and supports flashing the official Developer Kit firmware directly.

## Features

- Developed from the official reference design: every interface matches the reference board, and the **Developer Kit firmware can be flashed directly**
- Full **SUPER mode** support across Jetson Orin Nano 4GB/8GB and Jetson Orin NX 8GB/16GB modules (V1.1 and later)
- High-quality **6-layer ENIG PCB** with all-MLCC capacitors and gold-plated connectors
- Supports dual **NVMe SSD** storage slots and an **M.2 Key E** wireless card

| Camera | 2 × CSI, 22-pin |
| Other interfaces | Same as the reference board (40-pin expansion header, 12-pin button/debug header, fan header, power button) |
| RTC battery | Supported, MX1.25-2P, 3V |
| PoE | Not supported |
| Operating temperature | 0 °C to 45 °C |

::: warning Notes
- A 12V power supply is recommended (9V–19V input supported); ensure the power supply provides sufficient wattage.
- Improve cooling when the input voltage exceeds 15V under heavy load.
- The carrier board includes reverse-polarity protection on the power input, but never connect power in reverse.
- Each USB port group supplies up to 2.5A, with automatic overcurrent cutoff.
- Compared with the reference carrier board, the rear M.2 Key E and M.2 2230 slots are mirrored.
- Use **single-sided NVMe SSDs** only; double-sided SSDs may cause mechanical interference or short-circuiting.
:::

::: danger Safety Warning
**Only insert or remove the Jetson module when the carrier board is powered off.** Hot-plugging the module may permanently damage the module or carrier board.
:::

## Selected Functions and Interfaces

### Power Button (10)

- **While the system is running:** Short press to open the shutdown dialog; hold for 10 seconds to force power-off.
- **While the system is powered off:** Short press to power on.

### 40-pin Expansion Header (14)

The 5V output on the 40-pin GPIO expansion header includes back-feed protection and supplies up to 0.8A, shutting off automatically on overcurrent. Pin functions depend on the installed Jetson module.

![C1902 40-pin header pinout](/img/c1902-40pin.webp)

*40-pin expansion header pinout*

### 12-pin Button / Debug Header (11) and CAN Header (12)

The 12-pin header carries power LED, debug UART, Latch Set, system reset, Force Recovery (`FC REC`), and power button (`PWR BTN`) signals, as shown below. The unpopulated 4-pin CAN footprint (No. 12) exposes logic-level `CAN RX / CAN TX` signals from the Jetson module; for external transceiver wiring and testing, see [CAN Bus](/en/orin-nano-series/peripherals#_4-can-bus).

![C1902 12-pin debug header pinout](/img/c1902-12pin.png)

*12-pin button / debug header pinout*

### RTC Battery Connector (16)

The connector uses an MX1.25-2P housing for a 3V backup battery. Verify polarity before connecting; **never reverse the polarity**.

![C1902 RTC battery connector](/img/c1902-rtc.png)

*RTC battery connector*

Software configuration is required after installing the battery to enable the RTC clock. See [RTC Interface](/en/orin-nano-series/peripherals#_5-rtc-interface).
