# C1902 V2 Introduction

![C1902 V2 Banner](/img/c1902v2-banner.webp)

## Overview

The **C1902 V2** is a carrier board for **Jetson Orin Nano** and **Jetson Orin NX** modules. It is based on the NVIDIA reference carrier board design, its interfaces are compatible with the official developer kit, and it runs the Developer Kit firmware directly.

## Features

- Based on the reference design; flash the Developer Kit firmware directly
- Supports Orin Nano 4GB/8GB and Orin NX 8GB/16GB
- 6-layer immersion-gold PCB, all-MLCC capacitors and gold-plated connectors
- Supports NVMe SSDs and M.2 wireless cards
- Supports SUPER mode on the full Orin Nano / Orin NX lineup

## Specifications

| Item | Specification |
|------|---------------|
| Input voltage | 12V (9V–19V compatible) |
| Power connector | DC5525 |
| Supported modules | Jetson Orin Nano 4GB/8GB, Jetson Orin NX 8GB/16GB |
| Ethernet | 1 × Gigabit RJ45 |
| Wireless | 1 × M.2 Key E |
| Storage | 2 × M.2 Key M (NVMe SSD) |
| Display | 1 × DisplayPort 1.2 |
| USB | 4 × USB 3.2 Type-A (5Gbps) |
| USB-C | 1 × USB 3.2 Type-C (10Gbps) |
| Camera | 2 × CSI, 22-pin |
| Other interfaces | Same as the reference board, plus a 12-pin button/debug header, fan header and REC button |
| RTC battery | Supported, MX1.25-2P, 3V |
| PoE | Not supported |
| Operating temperature | -20℃–55℃ |

> - A 12V supply is recommended; 9V–19V input is supported. Make sure the supply provides enough power.
> - Improve cooling when the input is above 15V under heavy load.
> - The board has reverse-polarity protection on the power input, but do not reverse the supply.
> - Each USB port group supplies up to 2.5A; USB power is cut off on overcurrent.
> - The M.2 Key E and M.2 2230 slots on the back are mirrored compared with the reference board.
> - **Only insert or remove the module when the board is powered off.**
> - Use single-sided SSDs only; double-sided SSDs may collide with the board or short-circuit.

## Selected Features and Interfaces

### Power Input (1)

DC5525 power connector. 12V input is recommended; 9V–19V is supported. Improve cooling above 15V under heavy load.

### REC Button (13)

- **With the system powered off:** hold the button while applying power to enter recovery mode.

![C1902 V2 REC button](/img/c1902v2-rec-button.webp)

### 40-pin Expansion Header (9)

The 5V output on the 40-pin GPIO header has back-feed protection and supplies up to 0.8A; it shuts off on overcurrent. Pin functions depend on the module in use.

![C1902 40-pin header pinout](/img/c1902-40pin.webp)

### 12-pin Button/Debug Header (12)

The header carries power LED, UART, Latch Set, system reset, force recovery and power button signals. The pinout is shown below:

![C1902 12-pin button/debug header pinout](/img/c1902-12pin.png)

### RTC Battery Connector (16)

The connector is an MX1.25-2P and takes a 3V battery. Check the polarity when connecting; never reverse it.

![C1902 RTC battery connector](/img/c1902-rtc.png)

The RTC clock must be configured after the battery is installed. See [RTC Interface](/en/orin-nano-series/peripherals#_5-rtc-interface).
