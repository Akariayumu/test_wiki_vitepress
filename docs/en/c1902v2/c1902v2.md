# C1902 V2 Introduction

![C1902 V2 Banner](/img/c1902v2-banner.webp)

## Overview

The **C1902 V2** is an **industrial-grade** carrier board developed for **Jetson Orin Nano / Orin NX** modules. Redesigned from the official reference carrier board with industrial-grade key components and an optimized power architecture, it delivers improved stability and reliability while maintaining full functional compatibility with the official developer kit.

## Features

- Based on the official reference design: every interface matches the reference board, and the **Developer Kit firmware can be flashed directly**
- Full **SUPER mode** support for Orin Nano 4GB/8GB and Orin NX 8GB/16GB
- **Redesigned power supply** for lower heat generation and higher conversion efficiency
- High-quality **8-layer PCB** with strict impedance control on all high-speed traces
- **Entry-level industrial** operating temperature range (**-20 °C to 55 °C**) for enhanced stability and reliability

## Specifications

| Item | Specification |
|------|---------------|
| Input voltage | 12V (9V–19V compatible) |
| Power connector | DC5525 |
| Supported modules | Jetson Orin Nano 4GB/8GB, Jetson Orin NX 8GB/16GB |
| Ethernet | 1 × Gigabit RJ45 |
| Wireless | 1 × M.2 Key E (2230) |
| Storage | 2 × M.2 Key M (NVMe SSD) |
| Display | 1 × DisplayPort 1.2 |
| USB | 4 × USB 3.2 Type-A (5Gbps) |
| USB-C | 1 × USB 3.2 Type-C (10Gbps) |
| Camera | 2 × CSI, 22-pin |
| Other interfaces | Same as the reference board, plus a 12-pin button/debug header, fan header, and REC button |
| RTC battery | Supported, MX1.25-2P, 3V |
| PoE | Not supported |
| Operating temperature | **-20 °C to 55 °C** |

::: warning Notes
- A 12V power supply is recommended; 9V–19V input is supported. Ensure the power supply provides sufficient wattage.
- Improve cooling when the input voltage exceeds 15V under heavy load.
- The carrier board includes reverse-polarity protection on the power input, but never connect power in reverse.
- Each USB port group supplies up to 2.5A; USB power shuts off automatically on overcurrent.
- The M.2 Key E and M.2 2230 slots on the back are mirrored compared with the reference carrier board.
- **Only insert or remove the Jetson module when the carrier board is powered off.**
- Use **single-sided NVMe SSDs** only; double-sided SSDs may cause mechanical interference or short-circuiting.
:::

## Selected Functions and Interfaces

### Power Input (1)

Uses a DC5525 power connector. A 12V input is recommended (9V–19V supported). Improve cooling when operating above 15V under heavy load.

### REC Button (13)

- **With the system powered off:** Hold the `REC` button while applying power to enter Force Recovery mode.

::: tip External Power Button Wiring
The C1902 V2 replaces the former onboard power button with a dedicated `REC` button (auto power-on is enabled by default). To wire an external power button, use Pin 12 (`PWR BTN`) and Pin 11 (`GND`) on the **12-pin Button / Debug Header (12)**.
:::

![C1902 V2 REC button](/img/c1902v2-rec-button.webp)

*REC button location*

### 40-pin Expansion Header (9)

The 5V output on the 40-pin GPIO expansion header includes back-feed protection and supplies up to 0.8A, shutting off automatically on overcurrent. Pin functions depend on the installed Jetson module.

![C1902 40-pin header pinout](/img/c1902-40pin.webp)

*40-pin expansion header pinout*

### 12-pin Button / Debug Header (12) and CAN Header (11)

The 12-pin header carries power LED, debug UART, Latch Set, system reset, Force Recovery, and power button signals, as shown below. The unpopulated 4-pin CAN footprint (No. 11) exposes logic-level `CAN RX / CAN TX` signals from the Jetson module; for external transceiver wiring and testing, see [CAN Bus](/en/orin-nano-series/peripherals#_4-can-bus).

![C1902 12-pin button/debug header pinout](/img/c1902-12pin.png)

*12-pin button / debug header pinout*

### RTC Battery Connector (16)

The connector uses an MX1.25-2P housing for a 3V backup battery. Verify polarity before connecting; **never reverse the polarity**.

![C1902 RTC battery connector](/img/c1902-rtc.png)

*RTC battery connector*

Software configuration is required after installing the battery to enable the RTC clock. See [RTC Interface](/en/orin-nano-series/peripherals#_5-rtc-interface).
