# C1903 Introduction

![C1903 kit](/img/c1903-banner.webp)

*C1903 complete kit*

## Overview

The **C1903** is an **industrial-grade** carrier board upgraded and optimized from NVIDIA's reference design (also available as a complete system kit with an aluminum heatsink enclosure). Key components are selected to meet entry-level industrial-grade standards or higher, commonly used industrial peripheral interfaces are brought out directly, and the redesigned power architecture supports **SUPER mode** across the entire **Jetson Orin Nano / Orin NX** module lineup.

## Features

- Key carrier board components are rated to at least entry-level industrial-grade specifications for higher reliability and a wide **-20 °C to 50 °C** operating temperature range
- End-to-end power delivery optimization — from the DC input jack to the power-management ICs — provides full **SUPER mode** support across Jetson Orin Nano 4GB/8GB and Orin NX 8GB/16GB modules
- Newly designed **8-layer PCB** with strict impedance control on all high-speed traces
- Expanded interface set compared with the reference design, adding **one native USB 3.2 Type-A port (10Gbps)** and **two 4-pin GH1.25 USB 2.0 connectors**, alongside onboard-transceiver CAN, multiple UARTs, I²C, SPI, and GPIO connectors

## Specifications

| Item | Specification |
|------|---------------|
| Input voltage | 12V (9.5V–19V compatible) |
| Power connector | DC5525 |
| Supported modules | Jetson Orin Nano 4GB/8GB, Jetson Orin NX 8GB/16GB |
| Ethernet | 1 × Gigabit RJ45 |
| Wireless | 1 × M.2 Key E (2230) |
| Storage | 1 × M.2 Key M (2280, NVMe SSD) + 1 × M.2 Key M (2230, NVMe SSD) |
| Display | 1 × HDMI 2.1 |
| USB | 4 × USB 3.2 Type-A (5Gbps) + 1 × USB 3.2 Type-A (10Gbps) + 2 × USB 2.0 (GH1.25-4P) |
| USB-C | 1 × USB Type-C (USB 2.0, for flashing firmware) |
| Camera | 2 × CSI, 22-pin |
| Other interfaces | UART, CAN, I²C, SPI, GPIO |
| RTC battery | Supported, MX1.25-2P, 3V |
| PoE | Not supported |
| Operating temperature | **-20 °C to 50 °C** |

::: warning Notes
- A 12V power supply is recommended (9.5V–19V supported); improve cooling under heavy load when the input voltage exceeds 15V.
- Reverse-polarity protection is provided on the power input. Inspect power cables for aging or damage before use and replace worn cables promptly.
- Maximum output current per USB port group is 2.5A.
- Operate the product within the specified voltage and temperature ratings, and secure the carrier board with fasteners matching the recommended specifications.
- **Only insert or remove the Jetson module when the carrier board is powered off.**
- Single-sided NVMe SSDs are recommended to prevent mechanical interference or short-circuiting.
- Disconnect power immediately if sparks, smoke, a burnt smell, or any other abnormal behavior occurs after power-on.
:::

::: warning Native 10Gbps USB Port Note (No. 6)
The USB 3.2 Type-A port (No. `6`, 10Gbps) is routed directly from the Jetson module's native SuperSpeed lane (accordingly, the USB Type-C port No. `18` operates in USB 2.0 mode for firmware flashing). After flashing official firmware, you must replace the device tree to enable port No. `6`. See [USB Configuration](/en/orin-nano-series/usb-config) for instructions.
:::

## Selected Functions and Interfaces

### DC5525 Power Input (11)

The recommended input voltage is 12V, with a supported range of 9.5V–19V. Improve cooling under heavy load when the input voltage exceeds 15V.

| Module | Recommended Power Supply |
|--------|--------------------------|
| Jetson Orin Nano 4GB / 8GB | ≥ 45W |
| Jetson Orin NX 8GB / 16GB | ≥ 60W |

### Power / REC Buttons and Function DIP Switch (12, 13, 23)

![C1903 Power and REC buttons](/img/c1903-buttons.webp)

*Power and REC buttons*

- **Enter recovery mode:** With power disconnected, hold the `REC` button and apply power; alternatively, set **DIP switch 3** on the back to `ON` to enter recovery mode automatically on every power-up.
- **Power button:** While the system is running, press once to shut down or hold for 10 seconds to force power-off. While the system is off, press once to power on.
- **CAN termination and boot control:** Configured via the 4-position function DIP switch (No. 23) on the back, as detailed below:

![C1903 function DIP switch](/img/c1903-switch.webp)

*4-position function DIP switch*

| Position | Silkscreen | Function When `ON` | Default |
|----------|------------|--------------------|---------|
| 1 | `CAN 120R` | Enables onboard 120Ω CAN bus termination resistor | `OFF` (disabled) |
| 2 | `AUTO ON DIS` | Disables auto power-on when power is applied (press Power button to boot) | `OFF` (auto power-on) |
| 3 | `REC` | Automatically enters Force Recovery mode on every power-on | `OFF` (normal boot) |
| 4 | — | Reserved | `OFF` |

::: warning Reset DIP Switch 3 After Flashing
If you set DIP switch 3 (`REC`) to `ON` to enter recovery mode for flashing, **be sure to return it to `OFF` once the host detects the board or before rebooting after flashing**. Leaving it `ON` will trap the board in recovery mode on reboot.
:::

### GH1.25 Peripheral Connectors

Selected industrial peripherals are brought out via locking GH1.25 connectors. **Viewing each connector from the orientation shown below, pins are numbered from left to right (Pin 1 to Pin 6):**

![C1903 front GH1.25 connectors](/img/c1903-gh125-front.webp)

*Front GH1.25 peripheral connectors (No. 1–5)*

![C1903 back GH1.25 connectors](/img/c1903-gh125-back.webp)

*Back GH1.25 peripheral connectors (No. 19–22)*

| Interface | Connector | Pin 1 | Pin 2 | Pin 3 | Pin 4 | Pin 5 | Pin 6 |
|-----------|-----------|-------|-------|-------|-------|-------|-------|
| CAN0 | GH1.25-2P | CAN_L | CAN_H | — | — | — | — |
| I²C1 | GH1.25-4P | GND | SDA | SCL | 5V | — | — |
| UART2 DEBUG | GH1.25-4P | GND | RX | TX | 5V | — | — |
| UART1 | GH1.25-4P | GND | RX | TX | 5V | — | — |
| UART0 | GH1.25-4P | GND | RX | TX | 5V | — | — |
| USB 2.0-1 | GH1.25-4P | GND | D+ | D− | 5V | — | — |
| USB 2.0-2 | GH1.25-4P | GND | D+ | D− | 5V | — | — |
| GPIO | GH1.25-4P | GND | GPIO13 | GPIO7 | 5V | — | — |
| SPI0 | GH1.25-6P | GND | CS0 | MOSI | MISO | SCK | 5V |

::: warning Signal Logic Level Warning
- All **I²C, UART, GPIO, and SPI signal pins** on the GH1.25 connectors use **3.3V logic levels** (the `5V` pin on each connector is a peripheral power output only). Never drive 5V logic signals directly into these pins without level shifting, as doing so will damage the Jetson module!
- `CAN0` integrates an onboard CAN transceiver (exposing differential `CAN_L / CAN_H` directly). For software configuration and testing, see [CAN Bus](/en/orin-nano-series/peripherals#_4-can-bus).
:::

### RJ45 Ethernet (17)

- **Gigabit Ethernet (17):** Powered by an **RTL8111** controller; plug-and-play with no additional driver required.

### RTC Battery Connector (27)

Connector No. `27` on the back is an **MX1.25-2P** RTC backup battery connector for a **3V** coin-cell battery lead. Check the `+` polarity silkscreen on the PCB before connecting and **never reverse the polarity**. Software configuration is required after installing the battery to enable RTC timekeeping; see [RTC Interface](/en/orin-nano-series/peripherals#_5-rtc-interface).

The C1903 PCB outline measures **100 × 79 mm**, with a maximum overall envelope of **100 × 80.5 × 22 mm** including protruding connectors.
