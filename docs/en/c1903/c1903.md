# C1903 Introduction

![C1903 kit](/img/c1903-banner.webp)

*Figure 1. C1903 kit*

## Safety and Usage Notes

- Use the interfaces and power cable as described in this document to avoid damaging the cable or carrier board.
- Before use, inspect the power cable for aging or damage. Replace it if either condition is found.
- Operate the product only within the specified conditions, including input voltage and temperature. The customer is responsible for damage caused by improper operation.
- Secure the carrier board correctly with screws that meet the stated requirements to prevent damage.
- Disconnect power immediately if sparks, smoke, a burnt smell, or any other abnormal condition is observed after power-on.

## Overview

The **C1903** is an industrial-grade carrier board optimized from NVIDIA's reference design. Components are selected to meet at least entry-level industrial-grade requirements, and commonly used interfaces are brought out for easy integration. Its optimized power design supports SUPER mode across the complete Jetson Orin Nano and Orin NX module families.

## Features

- All carrier-board components are selected to at least entry-level industrial-grade specifications for higher reliability and a wider operating-temperature range.
- The complete power path, from the connector to the power-management ICs, is optimized to support SUPER mode across the full Orin Nano/NX family.
- Newly designed 8-layer PCB with strict impedance control on all relevant traces.
- Expanded interface set compared with the reference design, including one additional native USB 3.0 port and two standard USB 2.0 connectors.

| Parameter | Value |

| Supported modules | Orin Nano 4GB/8GB, Orin NX 8GB/16GB |
| Ethernet | 1x Gigabit Ethernet |
| Wireless | 1x M.2 Key E (2230) |

| Display | 1x HDMI 2.1 |
| USB | 4x USB 3.0 (5 Gbps), 1x USB 3.0 (10 Gbps) |
| USB-C | 1x Type-C (USB 2.0), for firmware flashing |
| Camera | 2x 22-pin CSI |
| Other interfaces | UART, CAN, I<sup>2</sup>C, SPI |
| RTC battery | 1x RTC backup-battery connector |
| Operating temperature | -20℃ to 50℃ |

*Table 2. Product specifications*

:::warning Notes
- The board accepts 12 V nominal input over a 9.5–19 V range. Improve cooling when the input exceeds 15 V.
- Reverse-polarity protection is provided on the power input.
- Maximum output current per USB group is 2.5 A.
- **Never insert or remove the Jetson module while the carrier board is powered.**
:::

## Selected Functions and Interfaces

### DC5525 Power Input

The recommended input is 12 V, with a supported range of 9.5–19 V. Improve cooling under high load when the input voltage exceeds 15 V.

| Module | Recommended power |
|--------|-------------------|
| Orin Nano 4GB/8GB | 45 W |
| Orin NX 8GB/16GB | 60 W |

*Table 4. Recommended power-supply ratings*

### Power and REC Buttons

![C1903 buttons](/img/c1903-buttons.webp)

*Figure 6. Power and REC buttons*

- **Enter recovery mode:** With power disconnected, hold the REC button and then apply power. Alternatively, set DIP switch 3 to ON to enter recovery mode automatically at every power-on.
- **Power button:** While the system is on, press once to shut down or hold for 10 seconds to force power-off. While the system is off, press once to power on.
- Set DIP switch 2 to ON to disable automatic power-on.

![C1903 DIP switch](/img/c1903-switch.webp)

*Figure 7. Function DIP switch*
