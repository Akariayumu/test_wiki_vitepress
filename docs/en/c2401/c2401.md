# C2401 Introduction

![C2401 Banner](/img/c2401-banner.png)

## Overview

The **C2401** is a high-density, compact carrier board developed for **Jetson Orin Nano / Orin NX** modules. Despite its small footprint, it provides a comprehensive set of industrial and machine-vision interfaces — including **dual Ethernet ports**, **dual USB 3.2 ports**, and rich expansion capabilities such as **4G/5G cellular module** support.

## Features

- Equipped with an automotive-grade **E-fuse** protection IC providing over-voltage, under-voltage, short-circuit, over-current, and reverse-polarity protection
- Ultra-low-resistance Buck converters paired with flat-wire alloy inductors for low heat generation and high saturation current
- **8-layer, 2 μin ENIG via-in-pad PCB** with a compact **55 × 92 mm** board outline (56 × 94 mm including protruding connectors)
- Dual USB 3.2 ports (10Gbps) and dual RJ45 Ethernet ports (1 × Gigabit + 1 × 2.5G supporting PTP and 16KB jumbo frames)
- Same-side (rear) M.2 Key M and Key E slot layout — swap the wireless card or NVMe SSD without removing the Jetson module

## Specifications

| Item | Specification |
|------|---------------|
| Input voltage | 12V (10V–30V supported; under-voltage protection at 9.5V, over-voltage protection at 31V) |
| Power connector | XT30 |
| Supported modules | Jetson Orin Nano 4GB/8GB, Jetson Orin NX 8GB/16GB |
| Ethernet | 1 × 2.5G RJ45 (16KB jumbo frames, PTP) + 1 × Gigabit RJ45 (9KB jumbo frames) |
| Wireless | 1 × M.2 Key E (2230) |
| Storage | 1 × M.2 Key M (2230, NVMe SSD) |
| Display | 1 × Mini HDMI 2.1 |
| USB | 2 × USB 3.2 Type-A (10Gbps) + 1 × USB 2.0 (GH1.25-4P) |
| USB-C | 1 × USB Type-C (USB 2.0, for flashing firmware only) |
| Camera | 1 × CSI, 22-pin |
| Other interfaces | UART, CAN, I²C, SPI, GPIO, USB 3.0 (via 30-pin expansion socket) |
| RTC battery | Supported, 2-pin backup battery connector, 3V |
| PoE | Not supported |
| Operating temperature | 0 °C to 45 °C |

::: warning Notes
- A 12V power supply is recommended (10V–30V input supported; under-voltage cutoff at 9.5V, over-voltage cutoff at 31V). Improve cooling under heavy load when the input voltage exceeds 15V.
- Reverse-polarity protection is provided on the power input, but never connect power in reverse.
- Each USB port group supplies up to 2.5A.
- **Only insert or remove the Jetson module when the carrier board is powered off.**
- Single-sided M.2 2230 NVMe SSDs are recommended to avoid mechanical interference.
:::

## Selected Functions and Interfaces

### XT30 Power Connector (1)

![C2401 XT30 power connector](/img/c2401-xt30.png)

*XT30 power connector polarity*

The recommended input voltage is **12V** (**10V–30V** supported; under-voltage protection threshold **9.5V**, over-voltage protection threshold **31V**).

| Module | Recommended Power Supply | USB-C PD Requirement (via PD-to-XT30 Trigger Cable) |
|--------|--------------------------|-----------------------------------------------------|
| Jetson Orin Nano 4GB / 8GB | ≥ 45W | 20V 2.25A |
| Jetson Orin NX 8GB / 16GB | ≥ 60W | 20V 3A |

::: warning Power Input Notice
**The onboard USB Type-C port (No. 3) is strictly for flashing firmware and does NOT accept power input.** Never plug a USB-C PD charger into the onboard Type-C port to power the board. The `USB-C PD Requirement` column above applies **only** when powering the board through the **XT30 power connector (No. 1)** using an external **USB-C PD to XT30 trigger adapter cable**.
:::

### Power / REC Buttons and Function DIP Switch (4, 5, 16)

- **Enter recovery mode:** With power disconnected, hold the `REC` button while applying power (recovery mode remains active for ~60 seconds and boots normally if no host connection is detected).

![C2401 REC button](/img/c2401-rec-button.png)

*REC button location*

- Alternatively, set **DIP switch 3** on the back to `ON` to enter recovery mode automatically on every power-up:

![C2401 DIP switch 3](/img/c2401-switch-rec.png)

*DIP switch 3 (REC)*

- **Power button:** While the system is running, press once to open the shutdown dialog or hold for 10 seconds to force power-off; while powered off, press once to power on.

![C2401 Power button](/img/c2401-pwr-button.png)

*Power button location*

- Set **DIP switch 2** on the back to `ON` to disable auto power-on, or set **DIP switch 1** to `ON` to enable the onboard 120Ω CAN bus termination resistor:

![C2401 DIP switch 2](/img/c2401-switch-power.png)

*DIP switch 2 (disable auto power-on)*

| Position | Silkscreen | Function When `ON` | Default |
|----------|------------|--------------------|---------|
| 1 | `CAN 120R` | Enables onboard 120Ω CAN bus termination resistor | `OFF` (disabled) |
| 2 | `AUTO ON DIS` | Disables auto power-on when power is applied (press Power button to boot) | `OFF` (auto power-on) |
| 3 | `REC` | Automatically enters Force Recovery mode on every power-on | `OFF` (normal boot) |
| 4 | — | Reserved | `OFF` |

::: warning Reset DIP Switch 3 After Flashing
If you set DIP switch 3 (`REC`) to `ON` to enter recovery mode for flashing, **return it to `OFF` once the host detects the board or before rebooting**. Leaving it `ON` causes mid-flash reboots to lock into recovery mode and time out.
:::

### 30-pin Expansion Socket (18)

A `2 × 15-pin`, 1.27 mm-pitch female expansion socket is located on the back. Pin 1 orientation and the full pinout are shown below:

![C2401 30-pin expansion socket](/img/c2401-ext-connector.png)

*30-pin expansion socket Pin 1 location*

![C2401 30-pin pinout](/img/c2401-pinout-30.png)

*30-pin expansion socket pinout*

::: warning Electrical and Configuration Notes
- `VCC_IN` passes the external supply voltage directly through (3A max continuous); `VDD_5V` and `VDD_3V3` supply up to 1A each.
- All **I²C, GPIO, SPI, and UART signal pins** use **3.3V logic levels**; do not drive 5V signals directly into these pins.
- `PG` (Power Good) outputs logic high while the Jetson module is operating normally.
- The USB 3.0 lane on pins 13 / 15 / 19 / 21 is disabled by default in stock firmware; see [USB Configuration](/en/orin-nano-series/usb-config) to enable it.
:::

### RJ45 Ethernet Ports (8, 9)

- **2.5G Ethernet port (8)** (adjacent to the USB Type-A stack, rear silkscreen `ETH2 2.5G`): Powered by an **RTL8125** controller supporting PTP and 16KB jumbo frames. **Requires driver installation after flashing** — see [2.5G Network Driver Installation](/en/orin-nano-series/network-driver).
- **Gigabit Ethernet port (9)** (toward the board corner, rear silkscreen `ETH1 1G`): Powered by an **RTL8111** controller supporting 9KB jumbo frames; plug-and-play with no extra driver required.

### M.2 Slot Layout (19, 20)

Both the M.2 Key M (2230 NVMe SSD, No. 19) and M.2 Key E (2230 wireless card, No. 20) slots are positioned on the rear side of the carrier board, allowing SSD or wireless module replacement without removing the Jetson module or heatsink on the front (see [Interface Layout](#interface-layout) above).
