## 产品简介

我们提供基于 Jetson Orin Nano / Orin NX 核心板的载板与套件，与原厂开发者套件完全兼容：

| 产品 | 定位 | 文档 |
| --- | --- | --- |
| **C1901** | 高性价比载板，基于公版方案删减优化 | [C1901 产品介绍](/c1901/c1901) |
| **C1902** | 第三方载板，与原厂完全兼容，全速 USB3.0 / Type-C | [C1902 产品介绍](/c1902/c1902) |
| **C1903** | 工业级载板/套件，支持全系列 SUPER 模式，提供双 M.2 与丰富扩展接口 | [C1903 产品介绍](/c1903/c1903) |
| **C2401** | 高密度小尺寸迷你套件，双网口、双 USB | [C2401 产品介绍](/c2401/c2401) |

核心板选型请参考 [Orin Nano 系列说明](/orin-nano-series/intro) 和 [Orin NX 系列说明](/orin-nx-series/intro)。
